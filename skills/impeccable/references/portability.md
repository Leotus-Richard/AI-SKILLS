# Impeccable portability boundary

This package bundles Impeccable 4.0.3 from pbakaus/impeccable at tag `skill-v4.0.3` (commit `68b1129634a1cdd9a0ba50b27376c71b4b083ae8`): the upstream hub (as `upstream/ORIGINAL-SKILL.md`) and 35 of its 38 reference playbooks, with the Apache-2.0 LICENSE and third-party NOTICE. Impeccable's native scripts and sub-agent definitions are not included, and its native runtime is not installed or executed.

## Routing

Use commands.json for owning playbook paths. Its disabled-native-only entries retain source navigation without granting authority to run helpers. Planning/review never authorize edits; UI edits never imply committing, deploying or changing tracker state. The host's own requirements for website/browser/media tasks still apply.

Native context.mjs includes an update-network path; therefore the wrapper reads local product/design/surface context manually. Do not run it as supposedly offline setup. Never run hook, pin, live-server, generation or repair commands merely because the original hub or a reference names them.

Script calls inside preserved playbooks are source-specific examples. In this default package use available authorized local observations and label missing automated coverage. Do not pretend a manual pass ran the detector, generated screenshots or independently reviewed a design.

## Reference conditions

- New/replacement visual authority: new-work.md; planning-only shape: shape.md.
- Craft immediately before UI edits: craft-floor.md.
- Operate/Read surfaces: operate.md.
- Native platform: ios.md/android.md and audit.native.md/adapt.native.md as applicable.
- Missing native documenter/asset/reviewer capabilities: reference/degraded/ playbooks, subject to local-only scope. Do not route to an external image provider.
- Hooks, live mode and doctor: their playbooks are native features and are not bundled. When the user asks about them, return the capability gap; `commands.json` links the upstream playbooks for reference.

## Dependencies and preservation

Portable reference use requires no npm installation. Impeccable's native detection and live tooling (htmlparser2, css-select, css-tree, domutils, puppeteer, localhost servers, hooks and provider bindings) are not bundled, so this package needs none of them and claims none of their capabilities. Do not translate a named source tool into a guessed tool call.

The upstream hub is named `ORIGINAL-SKILL.md` to avoid duplicate automatic discovery. `SOURCE.md` lists the few changes to upstream files. Preserve `LICENSE.txt` and `NOTICE.md` with them.
