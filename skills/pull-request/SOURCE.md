# Source and contribution notes

Original skill for this repository, contributed by the repository owner under Apache-2.0 (`LICENSE.txt`). No third-party source is involved.

The pull request template in `assets/pull-request-template.md` is the owner's: Description, Type of Change, How to Test, How to Validate, Checklist and Other Notes, with the boxes, placeholder steps and the Other Notes question as they gave them on 24 November 2026. The owner's rule that "Documentation updated" covers only a wiki or other documentation kept outside the repository is written into that checklist line.

The workflow, examples, gotchas and troubleshooting in `SKILL.md` were drafted on the same day at the owner's request, around that template. Two rules come from how this repository's own pull requests are written: say what was verified and what was not, and never tick a box for something that did not happen.

`evals/pull-request/` holds the Tier 3 cases for this skill. No live evaluation has run yet.
