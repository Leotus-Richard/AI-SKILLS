# Source and contribution notes

Original skill for this repository, contributed by the repository owner under Apache-2.0 (`LICENSE.txt`). No third-party source is involved.

The bug report template in `assets/bug-report-template.md` follows the six sections the owner listed on 24 November 2026: a summary of the bug, steps to reproduce, expected behavior, environment (operating system, package versions and so on), screenshots, and additional notes.

The workflow, example, gotchas and troubleshooting in `SKILL.md` were drafted on the same day at the owner's request, around that template. The rule to write "unknown" instead of inventing a step or a version comes from how this repository reports results: only what was observed.

`evals/bug-report/` holds the Tier 3 cases for this skill. No live evaluation has run yet.
